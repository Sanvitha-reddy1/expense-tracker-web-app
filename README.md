# Expense Tracker Web Application

A full-stack web application that allows users to track and manage personal expenses.  
The system enables users to add, view, and delete expenses while storing data persistently in a database and visualizing spending patterns.

---

## Features

- Add new expense entries
- View all recorded expenses
- Delete unwanted expense records
- Automatic calculation of total spending
- Interactive expense visualization using charts
- Persistent storage using a database

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- SQLite

### Visualization
- Chart.js

## Installation and Setup

### 1. Clone the repository

```
git clone https://github.com/yourusername/expense-tracker-web-app.git
```

### 2. Navigate to the project directory

```
cd expense-tracker-web-app
```

### 3. Install dependencies

```
npm install
```

### 4. Start the server

```
npm start
```

### 5. Open in browser

```
http://localhost:3000
```
